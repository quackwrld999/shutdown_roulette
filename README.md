# shutdown_roulette


If you find yourself using your PC late at night and don't want to shut it down, but sometimes feel you should, here's a fun solution. 

Try playing this roulette game! You will have two attempts to guess a number between 1 and 5. If you guess correctly, you can continue using your PC. However, if you don’t guess right, your PC will shut down automatically, allowing you to get some sleep. Enjoy!




how to convert this py file to exe:
1. pip3 install pyinstaller or pip install pyinstaller
2. pyinstaller --onefile --noconsole [file name]
3. navigate to dist folder then enjoy
